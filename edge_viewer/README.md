# 边界概率交互查看器

双击 `启动查看器.cmd`，浏览器打开 http://127.0.0.1:8765 。需要 Node.js（启动器会自动查找本机已有的 Codex Node）。所有依赖已保存在 vendor，使用时无需网络。文件只在本机读取，不上传。

默认自动加载 XAA3712010 示例。从下拉框选择其他模型后点击“加载所选模型”。左键拖动旋转、滚轮缩放、右键拖动平移；单击边显示概率及原 OBJ 顶点编号。

可以调整主色、颜色对比度、最低概率、表面显示、背面边透视、自动旋转，并保存当前三维画面为 PNG。默认线性映射：0 为浅色，1 为所选主色。对比度调整使用 p^gamma，只影响颜色；筛选和检查始终使用原始 boundary_probability。无预测使用灰色，始终保留显示。

## 文件和匹配

现有目录实际为 `../manual_test/v3`，包含 10 组 PLY 和 CSV，没有原始 OBJ 或 XLS。加载器自动列出成对文件。

当前 PLY 的顶点已按三角形拆开，不能套用原 OBJ 顶点编号。程序按 README 保证一致的三角形顺序，用 incident_triangle_ids 指定的两个面的坐标交集找唯一公共边。非唯一交集或无对应关系会报错，避免静默错配。该方式仅适用于此类保持三角形顺序的导出 PLY；其他 PLY 请使用原始 OBJ。

自定义导入支持三角网格 OBJ（包括负索引）、当前二进制小端 PLY，概率支持 CSV/XLS/XLSX。默认读取第一张工作表。必需列：edge_id、vertex_1、vertex_2、boundary_probability；PLY 额外需要 incident_triangle_ids（两个 1 起始三角形编号，分号分隔）。OBJ 按 1 起始顶点编号匹配并验证边存在，必须使用预测对应的原始顶点顺序。程序不自动三角化或焊接顶点。缺失预测可用空值或 nan。

`node verify.mjs` 检查全部十组数据的公共边匹配、几何唯一性、原始顶点对应一致性，以及 OBJ 和错误输入分支。`node server.cjs` 手动启动本地服务；Ctrl+C 停止手动启动的服务。

第三方依赖：Three.js 0.170.0（MIT）、SheetJS CE 0.18.5（Apache-2.0）。许可证见 vendor。
