# 边界概率交互查看器

双击 `启动查看器.cmd`，浏览器打开 http://127.0.0.1:8765 。需要 Node.js（启动器会自动查找本机已有的 Codex Node）。所有依赖已保存在 vendor，使用时无需网络。文件只在本机读取，不上传。

桌面版点击“打开模型与概率…”选择模型，自动配对并加载。浏览器版一次选择模型文件夹。右侧仅保留直接打开模型与概率的操作，不再显示模型列表。左键拖动旋转、滚轮缩放、右键拖动平移；单击边显示概率及原 OBJ 顶点编号。

可以调整主色、颜色对比度、最低概率、表面显示、自动旋转，并保存当前三维画面为 PNG。默认线性映射：0 为浅色，1 为所选主色。对比度调整使用 p^gamma，只影响颜色；筛选和检查始终使用原始 boundary_probability。无预测使用灰色，始终保留显示。

## 文件和匹配

支持当前 v4 的每模型独立子目录结构，以及旧 v3 同名 PLY / CSV。桌面版选择模型文件夹会列出当前目录和下一级子目录的配对文件。

当前 PLY 的顶点已按三角形拆开，不能套用原 OBJ 顶点编号。程序按 README 保证一致的三角形顺序，用 incident_triangle_ids 指定的两个面的坐标交集找唯一公共边。非唯一交集或无对应关系会报错，避免静默错配。该方式仅适用于此类保持三角形顺序的导出 PLY；其他 PLY 请使用原始 OBJ。

自定义导入支持三角网格 OBJ（包括负索引）、当前二进制小端 PLY，概率支持 CSV/XLS/XLSX。默认读取第一张工作表。必需列：edge_id、vertex_1、vertex_2、boundary_probability；PLY 额外需要 incident_triangle_ids（两个 1 起始三角形编号，分号分隔）。OBJ 按 1 起始顶点编号匹配并验证边存在，必须使用预测对应的原始顶点顺序。程序不自动三角化或焊接顶点。缺失预测可用空值或 nan。

`node verify.mjs` 检查全部十组数据的公共边匹配、几何唯一性、原始顶点对应一致性，以及 OBJ 和错误输入分支。`node server.cjs` 手动启动本地服务；Ctrl+C 停止手动启动的服务。

第三方依赖：Three.js 0.170.0（MIT）、SheetJS CE 0.18.5（Apache-2.0）。许可证见 vendor。

## STEP 模型查看

左侧新增“STEP 模型查看”：点击“选择 STEP 文件夹…”，在列表选择 `.step` / `.stp` 文件即可自动打开，也可使用“上一个 / 下一个”；也可以点击“打开 STEP 文件…”直接选择单个文件。桌面版会记住上次选择的位置。文件夹仅扫描当前层，不递归子文件夹。

桌面版和浏览器版均支持此功能，无需概率表、Python 或联网。保留 STEP 中的部件 / 曲面颜色，支持旋转、缩放、平移、表面开关、特征线颜色、自动旋转和 PNG 截图。曲面会三角化用于显示；特征线来自网格的锐边 / 开放边，不是 CAD 拓扑边编号，也不能直接对应原 OBJ 的概率或分片标签。STEP 固定显示在左窗口，OBJ / PLY 的概率或分片结果固定显示在右窗口，可同时保留和操作。

解析在独立 Worker 中执行，超过 3 分钟会终止并提示。损坏文件或无曲面文件显示错误，并保留上一个成功加载的模型。超大型装配受本机内存限制。

新增离线依赖：occt-import-js 0.0.23（LGPL-2.1），来源 https://github.com/kovacsv/occt-import-js ，未修改的 JS / WASM 和许可证保存在 vendor。npm 包 SHA-512 校验值：`RFfYQXYFX5C1mB1Aywm0ShcUKzXOr/VzTnlzhBSDJOR6YCAPt1HYCzeXWg1vwwjn/cUxwqRNhhtf1dlewoZYCQ==`。可从 https://registry.npmjs.org/occt-import-js/-/occt-import-js-0.0.23.tgz 获取对应版本包；上游包含构建脚本和源码说明。

运行 `node verify-step.mjs` 验证 STEP 几何转换和错误输入；可在命令后附加本地 STEP 文件路径进行真实解析验证。

### 按 BREP 面重新着色
打开 STEP 后，点击“按 BREP 面着色”。着色依据解析器提供的 BREP 面三角形范围，同一个面保持同色，每个面使用独立颜色（包括不同网格部件中的面），相邻面因此使用不同颜色。面数显示在按钮下方。再次点击“恢复 STEP 原始颜色”可恢复导入颜色，不修改磁盘上的 STEP 文件。缺少完整 BREP 面信息时按钮不可用。

## 一次选择与临时读出结果

桌面版只需选择 OBJ / PLY，自动匹配同目录概率表并加载。优先匹配“模型名__edge_boundary_probability”或“模型名”的 CSV / XLSX / XLS；当目录仅有一个模型时，还支持 edge_boundary_probability 和目录内唯一概率表。存在歧义时提示整理文件，不会任意选表。浏览器版通过一次选择文件夹授权读取模型和概率表。

桌面版读出不再询问保存位置，结果暂存于模型所在目录的 .edgescope-readout-随机标识 子目录，立即显示分片。点击“下载结果…”后才选择目录，生成独立、永久保留的结果副本，不覆盖已有文件。取消下载继续保留当前预览。模型目录需可写。

成功切换右侧概率模型、点击“删除临时结果”或正常退出会删除本次会话创建的临时结果；重复读出成功后替换旧临时结果，失败则保留上次成功结果。下载副本和外部载入的 segmentation.json 不会被清理。退出时先停止读出进程再清理；断电或强制终止可能遗留临时目录。清理校验失败会提示，绝不根据任意传入路径删除文件。

运行 node verify-workflow.cjs 检查配对、歧义、临时目录保护、真实读出、下载/取消和正常退出清理；需已构建 Windows 读出运行库。

## 左右对比布局

从左到右依次为 STEP 操作栏、STEP 窗口、概率/分片窗口、模型与读出操作栏。左右各有独立的相机、旋转/缩放/平移、表面开关、自动旋转、状态和截图按钮。左侧 BREP 着色只作用于 STEP；右侧可切换网络边概率和几何分片结果。

两侧加载互不替换，右侧读出期间仍可加载和查看 STEP。更换 STEP 不会清理右侧临时结果；只有更换右侧模型、主动删除或正常退出才清理本次临时结果。

## 视角、主题与手动合并

顶部“视角对齐并联动”勾选后，以左侧当前视角对齐两侧；随后在任一窗口旋转、缩放或平移都会同步，取消勾选恢复独立操作。这是相机联动，不是自动配准几何；两个文件的坐标朝向需要本身一致。顶部“主题”切换浅色 / 深色，文字、面板、状态栏及三维背景一起改变，并记住选择。

右侧已移除模型列表及加载所选模型按钮，两侧均移除背面透视控件。STEP 直接打开文件就立即显示；打开目录自动载入首项，列表选择及上一个 / 下一个立即载入，到两端时对应按钮禁用。

右侧有分片结果时，点击“选择几何分片”，再点击模型上的面片多选，选中片显示橙色，再次点击取消。至少选择两个片后点击“合并”。合并更新标签和边界，下载结果会包含合并后的 patches.obj、patches.ply、face_labels.csv、boundary_edges.csv、segmentation.json 和 report.json。原始模型、概率和已下载副本不修改；加载外部标签后合并也会创建新的临时结果。允许手动合并不相邻的片，报告会如实记录是否连通。

验证：node verify-view-settings.mjs 检查相机联动/解绑及主题；node verify-workflow.cjs 包含合并导出与临时结果生命周期测试。
