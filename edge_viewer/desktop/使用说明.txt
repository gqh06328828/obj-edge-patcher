EdgeScope 1.0.0 · Windows x64 免安装桌面版
========================================

启动
双击本文件夹里的 EdgeScope.exe，或者上级文件夹里的 EdgeScope 快捷方式。
不需要安装 Node.js、Python，也不需要浏览器或网络。
关闭窗口即可退出软件。

加载自己的模型
1. 点击“① 选择模型”，选择 OBJ 或 PLY 文件。
2. 点击“② 选择概率表”，选择 CSV、XLS 或 XLSX。
3. 点击“③ 加载模型与概率”。
   同目录的 <模型名>__edge_boundary_probability.csv/xlsx/xls
   或 <模型名>.csv/xlsx/xls 会自动匹配，加载前可更换。

批量浏览
点击“选择模型文件夹”，软件会寻找成对的模型与概率表。
从模型列表中选择后，点击“加载所选模型”。
如果同名 OBJ 和分区 PLY 同时存在，优先使用 OBJ。
首次运行会尝试读取软件文件夹旁的 manual_test/v3。

交互
左键拖动：旋转；滚轮：缩放；右键拖动：平移。
单击边：显示原始概率、边编号和原 OBJ 顶点编号。
左侧可调整主色、颜色对比度、最低显示概率、表面和背面边。
概率越高颜色越深；对比度仅影响颜色，不改变概率。
点击“保存图片”，选择保存位置即可导出 PNG。

快捷键
Ctrl+O          选择模型
Ctrl+Shift+O    选择概率表
Ctrl+Enter      加载已选文件
Ctrl+0          重置视角
Ctrl+Shift+S    保存图片
F11             全屏

数据要求
OBJ 必须是预测时使用的原始三角网格，顶点编号和顺序必须保持一致。
概率表第一张工作表需包含以下列：
edge_id, vertex_1, vertex_2, boundary_probability
编号从 1 开始，概率在 0–1 之间；无预测使用空值或 nan，显示为灰色。
当前 PLY 支持 v3 的 binary_little_endian 三角网格格式，
还需要 incident_triangle_ids 列，两个相邻三角形编号以分号分隔。
PLY 必须保持预测对应的三角形顺序；程序会核验唯一公共边。
无法匹配时会显示错误，建议改用原始 OBJ。

移动到其他电脑
复制整个 EdgeScope-Windows 文件夹，不能只复制 exe。
模型和概率表不包含在程序中，可以另行复制，然后在软件内选择。
软件会在自己的 user-data 文件夹里保存窗口缓存和上次选择的位置。

组件
Electron 44.3.0 / Three.js 0.170.0 / SheetJS CE 0.18.5
相关许可证随软件保存在 LICENSE、LICENSES.chromium.html
及 resources/app/vendor 中。

几何分片读出（新增）
加载模型与概率后，展开左侧“几何分片读出”，点击运行并选择结果保存目录。
算法结合二次曲面代理、边概率、片数惩罚和最小规模约束；结果自动按片着色。
默认每片至少 80 个三角形、总面积的 0.04%。这些门槛可调，过大会吞掉真实小面。
可切换“网络边概率 / 几何分片结果”，也可加载保存的 segmentation.json。
结果包括彩色 PLY、按片分组 OBJ、面标签、切边表和检查报告。
分割计算使用随软件打包的 Python / NumPy，关闭程序会停止尚未完成的计算。
当前输出仍沿原三角网格边界，不是已经重建的 STEP；圆环和复杂过渡面仍需检查。
