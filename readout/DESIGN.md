# 曲面连续性读出 v2.1

输入为原始 remesh 三角网格与逐边 `boundary_probability`，输出为连通三角形区域。边界始终沿原网格边，不切三角形、不移动顶点。STEP、参考面编号和 PLY 原颜色都不参与推理。

本版直接替换默认判定流程，没有旧算法模式开关，也不把旧分割结果作为输入或保护标签。原有线性二次代理统计量继续用于快速组装和候选评分；最终合并新增独立的曲面连续性判据。Git 历史仍可回溯。

## v2.1：自由曲面补充规则

叶片不一定能由一个全局解析曲面或低阶高度函数解释。因此，v2.1 在共同曲面证据不成立时，增加 `freeform_evidence.py` 的局部判断。**全局拟合残差大不再单独阻止自由曲面合并，也不单独支持重新切分。** 新规则仍保守，不能保证所有叶片过分割已解决，实际记录见 `RESULTS_V21.md`。

首先统计整条公共边界，所有概率必须有效。边长加权平均概率不超过 0.15，且高概率片段较少时，进入局部几何检查。对平均概率较高但不超过 0.85 的接口，还检查它是否比两侧邻域形成明显的概率凸起，区分普遍偏高的区域和边界线：

- 每条边在七层面邻域中，沿两侧中心连线的切平面投影方向，取距离超过该边长度 1.2 倍的两侧边概率中位数，用较高一侧作为背景。
- 当边概率超过 0.5 且比背景高出 0.15 时，记为概率边界线证据；这种证据超过接口长度的 10%，或平均正概率差超过 0.12，拒绝该自由曲面合并。
- 概率超过 0.95 的边超过接口长度 8% 时直接拒绝。缺少背景支撑时也不通过这条较高概率规则。原始概率没有被改写或替换为 calibrated 列。

概率通过后，检查全部接口边的局部几何：

1. 任意接口边两侧原始法向夹角超过约 24°，拒绝该规则。
2. 在三、五、七层面邻域建立局部切向坐标系，分别用两侧网格顶点拟合三次局部高度函数。它们是局部近似，不要求整片满足三次方程。
3. 至少一个尺度需要有充分支撑、位置/法向残差合格，且接口处的位置、单位法向和曲率矩阵相容。比较接口处的曲率，而不是两侧平均曲率，以免把平滑的曲率梯度误判为突变。
4. 不合格局部检查累计超过边界长度的 8% 时拒绝合并。已通过的局部结果只依赖原网格，缓存后在后续区域合并中复用。

这条规则只验证消除接口的证据，不返回全局 CAD 曲面方程。每次合并都检查当前全部公共接口，不能通过某个低概率缺口跨越整体高概率边界。它允许有限噪声，不能排除很短的真实曲率变化被忽略。

采用同样规则否决不必要的重新切分。最小尺度清理也优先选择局部证据支持的邻片，再考虑普通概率/代理评分；这一步不要求小片达到全局独立拟合所需的 48 面，因为它本来就在执行最小尺度约束。报告仍计入强制合并。

已经以自由曲面证据合并的片，在后续单三角形细化中暂不接受或失去三角形，以免又被全局二次代理拉动边界。这个保守处理也可能留下不够平滑的边界。解析曲面的原有细化继续执行；最小尺度清理后额外执行一次相同合并复核。

| 新参数 | 默认值 | 含义 |
|---|---:|---|
| `freeform_probability` | 0.15 | 直接进入局部几何检查的平均概率上限 |
| `freeform_curvature` | 0.50 | 接口两侧局部曲率矩阵相对容差，另加 `0.005 / 局部跨度` |
| `freeform_outlier_fraction` | 0.08 | 整条接口允许的局部几何检查失败长度比例 |
| `freeform_ridge_contrast` | 0.15 | 判为概率边界线所需的概率与背景之差 |

这些参数同时支持 `Config` 和同名连字符形式的 CLI 参数，如 `--freeform-probability 0.15`；界面没有新增控件。模型适配和初始化仍是局部启发式，不能保证已有高概率边界被整条准确恢复。合成“高概率边界保留”测试针对已有候选区域的合并，不是完整 BRep 精度评价。

以下保留共同曲面规则和整体流程的详细说明。

## 规则与实现

`geometry_readout.py` 负责拓扑检查、区域图、合并、重新切分、细化与输出；`surface_evidence.py` 负责同一曲面的几何证据。

### 1. 连通微区域和快速组装

三角形是图节点，共享原边构成邻接。按概率和法向差形成内部微区域，再利用可加的 10×10 定向二次代理统计量快速组装，避免对数千个微区域的所有组合执行昂贵曲面检查。

```text
Δ_proxy = D(A∪B) - D(A) - D(B) - region_penalty - C(A,B)
C(A,B) = Σ_公共边 boundary_weight · edge_length / sqrt(total_mesh_area)
          · clip(log((1-p)/p), -probability_clip, probability_clip)
```

`D` 是带位置和法向约束的二次隐式代理残差。坐标按包围盒对角线归一化；位置尺度为中位边长乘 `distance_edges`。代理法向在保留约 25° 折角的前提下平滑两轮。有限概率代价允许恢复低概率真实折痕。

### 2. 同一曲面判断加入同一个合并过程

快速组装后，复用同一个区域邻接图、优先队列和合并更新函数，检查原先因概率或代理误差未能合并的邻片。依次尝试以下解释，选第一个通过完整验收的模型：

| 报告名称 | 几何解释 |
|---|---|
| `plane` | 同一平面 |
| `revolution` | 同一圆柱或圆锥，半径沿轴向为常量或线性变化 |
| `sphere` | 同一球面 |
| `torus` | 圆形母线的旋转面，适用于部分圆环形圆角、过渡面 |
| `graph2` | 同一局部二次高度函数 |
| `graph` | 同一局部三次高度函数，允许更一般的规则曲率变化 |

圆锥通过单位法向和近似距离验证，**不要求隐式梯度大小恒定**，因此不会仅因轴向半径变化而拒绝合并。高度函数只在适合单值图面的法向覆盖范围内使用，不能环绕整个圆柱。

轴候选来自法向协方差、网格主方向，以及位置/法向的旋转对称约束。主方向只是待验证候选，不表示所有圆柱必须平行。未读取 STEP 轴线。

一次合并必须同时满足：

1. **支撑充分**：两侧各有至少 `continuation_min_faces` 个三角形。
2. **共同模型成立**：拟合同一个模型，分别检查 A、B 的位置和单位法向误差。
3. **双向预测成立**：A 独立拟合后解释 B，B 独立拟合后解释 A。旋转模型共享候选轴，分别估计半径/锥度/圆弧参数；图面共享坐标系，分别估计系数。
4. **曲率一致**：在联合样本上比较两侧模型的切平面法向导数矩阵，检查曲率大小与方向。仅仅相切、平均法向接近不足以合并。
5. **全量复核**：采样用于拟合和初筛，接受前对两侧所有三角形分别检查共同模型和交叉预测。

拟合使用面积权重。误差验收要求 95 分位不超过门槛，且最大误差不超过门槛的 3 倍。曲率比较也采用分位数与最大值约束。它容忍有限 remesh 噪声，但不是对任意脏数据的严格曲面等价证明。

曲面验收使用原始三角形法向，避免只因法向平滑而掩盖真实分界。每次合并 AB 后再考虑 C，都重新拟合、检验整个 AB 与 C，不能由两次局部相似直接推断整体等价。

### 3. 几何与高概率冲突时的决定

全部证据通过时，以 `-region_penalty` 作为确定的合并优先级；概率代理倾向于不切开的接口优先级为其两倍，先组装内部区域，再考虑几何覆盖概率。共同曲面证据仍允许推翻高概率直线、闭环或轴向截断。该优先级用于排序，**不声称这次合并降低原二次代理能量**。

已由曲面证据合并的区域，继续合并时也必须重新通过几何判断，不能直接被普通代理评分吞入不兼容邻片。区域成员记录在各轮之间传递。

证据不足则保守保留边界，不把拟合失败解释成两个真实曲面一定不同。普通评分、前沿生长和边界细化仍使用概率。最小尺度强制合并是显式例外，记录在 `forced_merges`。

同一平面上被高概率线人为拆开的区域现在允许合并。这符合“几何等价面可以合并”的目标，不能用恢复每一个 STEP 历史分面来评价这条规则。

## 重新切分与最终约束

- 对代理残差大的区域提出两个连通子片；若新曲面规则证明两侧连续，则否决切分，避免重新拆开已经合好的圆锥。
- 其他切分仍要求两个子片满足尺度约束、代理评分改善，保留低概率真实折痕的恢复途径。
- 小片只能并入邻片，按代理损失选择。最少面数和最小面积是硬下限；强制合并可能牺牲真实小面，不应靠增大它们掩盖过分割。
- 边界单三角形细化检查连通与尺度；可靠曲面的接收区域还要检查该三角形是否在几何容差内。
- 细化有移动后，再以**相同规则和阈值**复核合并机会；这一轮只接受通过曲面证据的合并。
- 最终遍历检查所有三角形均赋值、每片连通并满足尺度。原始断开分量本身小于门槛时直接报错，不连接不相邻几何。

算法是确定性的分层局部启发式，不是全局最优求解器。报告中的 `energy_before_minimum`、`energy_after_minimum`、`final_energy` 是诊断二次代理；几何合并可能使它增加，不能用其单调性判断 v2 正确与否。

## 默认参数及含义

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `min_faces` | 80 | 最终每片三角形数硬下限 |
| `min_area_fraction` | 0.0004 | 每片至少占总面积 0.04% |
| `normal_sigma` | 0.20 | 代理法向容差，也是连续性法向容差基准 |
| `distance_edges` | 0.35 | 代理位置尺度为中位边长的 0.35 倍 |
| `boundary_weight` | 0.002 | 概率评分权重；不能否决已通过的几何证据 |
| `probability_clip` | 2.2 | 对数概率代价裁剪 |
| `region_penalty` | 0.0008 | 新增片代理代价及几何合并排序基准 |
| `seed_faces` | 64 | 内部微区域最大面数 |
| `continuation_distance` | 0.60 | 连续性位置容差乘数，默认约为中位边长的 0.21 倍 |
| `continuation_normal` | 0.40 | 连续性单位法向差容差乘数，默认差值 0.08，约 4.6° |
| `continuation_curvature` | 0.25 | 两侧曲率矩阵相对容差，另加 `0.005 / 联合区域跨度` 小绝对项 |
| `continuation_min_faces` | 48 | 各侧独立判断所需面数；太少时局部模型不稳定 |
| `surface_samples` | 192 | 拟合最大样本数；按原三角形顺序均匀选取，全量误差验收不采样 |
| `split_passes` / `refine_passes` | 2 / 2 | 重新切分/边界细化最大轮数 |

共同模型使用基本门槛；解析模型交叉预测容差为其 1.5 倍，图面外推为 2.5 倍，但仍需通过相同的共同模型、曲率检查。增大连续性容差通常允许更多合并，也增加误合并风险。最小片尺度应根据需要保留的真实小面设置。

## 运行

桌面仍按原方式选择模型、CSV/Excel 概率并运行几何分片，新规则默认生效，无版本开关。已有界面参数继续生效；新增连续性参数目前通过 Python 配置和命令行提供，没有新增界面控件。

```powershell
.\readout\run.ps1 -Mesh 'model_remesh.obj' -Probabilities 'model__edge_boundary_probability.csv' -Out '.\readout\results\new-run'
```

```shell
python readout/geometry_readout.py --mesh model.obj --probabilities edges.csv --out results/new-run --continuation-distance 0.60 --continuation-normal 0.40 --continuation-curvature 0.25 --continuation-min-faces 48
python -m unittest discover -s readout -p test_readout.py -v
```

Python API 不变：`Readout(vertices, faces, incident, probabilities, edge_positions, Config(...)).run()` 返回 0 起始三角形标签和报告。只依赖 NumPy。Windows 包需要同时包含 `geometry_readout.py`、`surface_evidence.py`、`freeform_evidence.py`。

## 输入输出

CSV 需要 `edge_id,vertex_1,vertex_2,incident_triangle_ids,boundary_probability`。编号从 1 开始，相邻三角形以分号分隔；只使用原始概率列，缺失预测按中性代价处理。严格核对全部边拓扑，拒绝错配、重复、非流形、退化三角形和不一致绕序。PLY 仅支持既有 v3 二进制格式，通过精确坐标恢复拓扑。

- `segmentation.json`：按输入三角形顺序保存标签与输入 SHA256；`edgescope.segmentation.v1` 是文件格式版本，算法版本在报告中。
- `face_labels.csv`、`boundary_edges.csv`：原始面/边编号对应的结果。
- `patches.obj`：double 精度坐标文本，每片一个组，面按片重排，不能直接套用原 CSV 面编号。
- `patches.ply`：输入面顺序、分片颜色，位置以 float32 保存。
- `report.json`：方法 `surface-continuation-readout-v2.1`、参数、输入和三个实现文件 SHA256、连通/尺度验收、曲面合并事件、切分否决次数；`freeform` 事件表示局部证据支持，没有对应的全局解析方程。

事件中的锚点是原三角形编号，左右面数为合并当时规模；模型名称是该次解释，不是重建完成的 CAD 面类型。输出不覆盖已有文件，正常完成且通过报告验收才算成功。

## 验证与限制

27 项合成测试覆盖平面误边、圆柱闭环、圆锥多圈截断、规则变曲率、圆环过渡面、低概率真实折痕、不同锥度/轴向、相切但曲率不同、传递合并泄漏、带噪旋转缩放、重新切分、小孤岛、断开分量，以及自由曲面、概率缺口、缺失预测、弥散高概率和中等概率边界线。历史记录见 `RESULTS_V2.md`，本轮记录见 `RESULTS_V21.md`。

片数减少与结构验收不等于 STEP 面匹配精度提升。没有完成独立真值的边界精度/召回率评价，不能保证已有正确边界完全不变。轴估计不稳定、严重噪声、很窄的曲面、法向覆盖不足、非圆形旋转母线和复杂自由曲面仍可能过分割；容差内的真实差异也可能被合并。三角形编号采样可能受输入顺序影响。

本版没有切三角形、求曲面交线、投影顶点或构造 STEP/BRep，不承诺恢复建模历史。

参考背景：[Yan 等二次曲面分割研究](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/Variational-mesh-segmentation-via-quadric-surface-fitting.pdf)、[CGAL Shape Detection](https://doc.cgal.org/latest/Shape_detection/index.html)。本实现是上面明确列出的启发式规则，不是论文逐项复现，也没有调用 CGAL。
