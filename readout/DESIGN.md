# 几何与概率联合分片读出 v1

目标是恢复接近 CAD 面的**连通三角形区域**，而不是把每条高概率边独立切断。输入只有预测对应的 remesh 模型和逐边概率；不读取 STEP、原 PLY 的分区颜色或参考面标签。

## 两个关键要求如何落地

1. **低概率边也可能需要分隔**：概率只提供有上限的软代价。若两侧合成一个片后，曲面代理的拟合误差显著增加，算法保留边界。一个低概率缺口不会自动让整个边界失效。
2. **不能碎片化**：目标函数惩罚片数，决策在区域之间进行；最终每片必须连通，并同时满足最少三角形数和最小面积。未达到最小尺度的片只能与相邻片合并，选择联合目标损失最小的邻片。每一次强制合并都计入报告，不伪装成几何上无损。

这里对“碎片”的可执行定义是：不连通标签，或低于用户给定最小尺度的区域。它不是对所有视觉上不合理分片的数学识别器。细长碎条可能满足面积限制，因此报告另列周长紧致度供检查。不能因为细长就删掉，否则真正的倒角和圆角也可能被删掉。

## 联合目标

三角形为图节点，共享边对应邻接。面标签为 z，片数 K。最小化：

```text
E(z, Q) = Σ_R D(R, Q_R) + Σ_e c_e · [z_left ≠ z_right] + λ_K K

c_e = λ_B · (edge_length / sqrt(mesh_area))
      · clip(log((1-p_e)/p_e), -L, L)

每片 R 连通
|R| ≥ min_faces
area(R) / total_area ≥ min_area_fraction
```

- p 低：切开有代价，但代价有限，不是“禁止切开”。
- p 高：切开有收益，但还要支付新增片的代价，且满足区域几何和最小尺度约束。
- 缺失预测：该边概率项为中性 0，仍参与几何分割；不伪造预测。
- 以真实面积、边长归一化，避免直接被三角形密度或模型单位主导。最少三角形数仍是显式分辨率相关约束。
- 默认概率裁剪 L=2.2，防止接近 0/1 的错误预测压倒其他证据。这里没有用 STEP 来学习校准系数。

### 曲面代理

每片拟合一个带法向约束的二次隐式函数：

```text
F(x,y,z) = a x² + b y² + c z² + d xy + e xz + f yz
           + g x + h y + i z + j

D(R,Q) = Σ_(t∈R) normalized_area(t) ·
         [ F(centroid_t)² / σ_d²
           + ||∇F(centroid_t) - smoothed_normal_t||² / σ_n² ]
```

先将坐标按包围盒对角线归一化；σ_d 默认取中位边长的 0.35 倍。法向在保留大于约 25° 折角的前提下做两次邻域平滑，减少 remesh 引入的局部波动。

这是一种**定向二次代理的线性最小二乘误差**，不是精确点到曲面的欧氏距离。法向项固定梯度尺度，避免全零函数或仅靠代数零点“解释一切”。平面、圆柱面和球面适合这种代理；一般圆锥仅为近似，圆环面、变半径圆角、自由曲面也只能局部近似。v1 没有完整的 plane/cylinder/cone/sphere/torus/B-spline 多模型选择，不应把输出标签称为已经识别的 CAD 面类型。

使用 10×10 的累积最小二乘矩阵、10 维右端项和区域面积作为可加统计量。相邻区域合并时不需要重扫所有三角形，因此可处理当前十万面级模型。

## 优化流程（已实现）

1. **输入校验**：保留三角形顺序，核对 CSV 覆盖每条边及其相邻三角形，拒绝重复/遗漏、越界、非流形、退化三角形和不一致绕序。对 v3 PLY 只用精确坐标恢复被拆开的公共边。
2. **连通微区域初始化**：按概率与法向变化排序，在最大种子规模内合并。此步骤的阈值只影响初始化，不固定最终边界；细区域只是中间工作单元，不直接输出。
3. **区域邻接图合并**：聚合整个公共边界上的证据。计算合并的完整能量变化；优先队列仅接受降低目标的合并。每次合并更新邻域，保持连通。
4. **重新切分**：对几何残差足够大的片提出两个连通子片，用几何种子和受概率影响的图上前沿生长得到候选。只有两个子片都有足够支撑且总能量下降时才接受。默认最多两轮，避免一次误合并永远不可逆。
5. **最小尺度约束**：对不合格片逐个选择损失最小的邻片进行强制合并。保留所有三角形，不删除面、不把不相邻的岛强行拼成一个标签。这一步允许目标值增加，以兑现最小尺度要求。
6. **边界调整**：在边界附近尝试单个三角形重分配，同时重新计算区域拟合和边界代价，只接受下降；用保守的局部连通检查和区域规模检查防止断裂或产生小片。
7. **最终验收**：检查面覆盖、每片连通和最小规模。原始断开分量若本身小于硬门槛，直接报告无法满足约束，不输出伪造的“无碎片结果”。

这是确定性的局部启发式优化，不是求得全局最优的 multicut/graph-cut 求解器。重新切分候选和局部边界移动都可能错过更好的划分。

## remesh 边界错位怎么处理

v1 通过整个区域的拟合与边界附近重分配，减少单条边预测噪声造成的绕行，但输出仍然以现有三角形为单位，边界只能沿现有网格边。

如果原 STEP 边界穿过一个 remesh 三角形，严格恢复它需要下一阶段：拟合相邻真实曲面 → 求交线或求边界带内的连续曲线 → 分裂被穿过的三角形 → 在误差容限内投影/重建局部网格 → 构造和验证 BRep。这会改变拓扑和顶点位置，v1 未实现，也没有偷偷移动输入顶点。

同一解析曲面上两个人为拆开的 BRep 面，如果概率也无有效信号，仅凭 remesh 几何可能不可辨识。不能承诺恢复原 STEP 的全部建模历史。

## 默认参数及取舍

| 参数 | 默认 | 含义 |
|---|---:|---|
| min_faces | 80 | 每片三角形数的硬下限 |
| min_area_fraction | 0.0004 | 每片至少占总面积 0.04% |
| normal_sigma | 0.20 | 定向梯度/法向容差；增大通常更宽松，可能少分 |
| distance_edges | 0.35 | 位置残差容差相对于中位边长 |
| boundary_weight | 0.002 | 概率项权重；增大更信任网络 |
| region_penalty | 0.0008 | 每新增一片的代价；增大偏向少片 |
| seed_faces | 64 | 中间微区域最大面数 |

不能只增加 min_faces 来掩盖碎片：真实小 CAD 面会被牺牲。应先检查网络误差、几何容差和代理模型是否合适，再设最小可接受物理尺度。实际批量使用建议根据最小需要保留的倒角宽度选择面积门槛，并把最少面数作为辅助，而不是把某个固定值当通用真理。

## 使用

桌面版：加载模型和概率 → 展开左侧“几何分片读出” → 设置最小片尺度 → 点击运行 → 选择结果保存文件夹。完成后自动显示彩色分片。可在“查看内容”中切换网络概率与分片结果。

也可运行：

```powershell
.\readout\run.ps1 -Mesh '模型_remesh.obj' -Probabilities '模型_remesh__edge_boundary_probability.csv' -Out '.\readout\results\新结果'
```

Python API：

```python
from geometry_readout import load_mesh, read_predictions, validate_mapping, Readout, Config
v, f = load_mesh(mesh_path)
prediction = read_predictions(csv_path)
positions = validate_mapping(v, f, prediction, mesh_path.lower().endswith('.obj'))
labels, report = Readout(v, f, prediction[2], prediction[3], positions, Config()).run()
# labels[t] 为输入第 t 个三角形的 0 起始片编号
```

桌面版通过独立 Python 子进程调用该接口，界面不等待同步计算；支持取消。Python 与 NumPy 随完整程序分发，无需用户额外安装。独立命令行需要 NumPy。命令行读入 CSV；桌面版可将 Excel 第一张表转为 CSV 并保留转换文件。

## 输出

- `patches.ply`：彩色分片，保留输入三角形顺序；为显示颜色复制顶点，位置写为 float32。
- `patches.obj`：每片一个 `g patch_N`，以 double 精度文本保留坐标；**按片重排了面**，不能把原 CSV 的三角形编号直接用于这个 OBJ。
- `face_labels.csv`：原始 1 起始三角形编号到 1 起始片编号。
- `boundary_edges.csv`：每条原边是否切开、两侧片编号和原概率。
- `segmentation.json`：桌面查看器可载入的标签，包含输入模型 SHA256，避免给另一个模型套标签。
- `report.json`：参数、面覆盖与连通验收、每片规模、强制合并次数、低概率切边/高概率保留边统计、耗时和输入哈希。

输出目录不能覆盖已有结果。桌面会自动创建带时间戳的新子目录。中止或失败的任务可能留下日志或不完整文件夹；只有正常完成并生成通过检查的 report 才算成功结果。

## 测试与评价边界

单元测试覆盖：低概率双平面折痕、随机高概率平面噪声、圆柱完整性、小高概率闭环、尺度/平移不变性、缺失概率、无法满足的断开分量、重新切分错误合并，以及平面上有充分网络证据的真实候选边界。

当前样本只做输入映射和结构有效性检查，未完成与 STEP 面的边界精度/召回率或实例匹配评价。**片数与 STEP face_count 相同不等于分割正确。** 下一轮应从独立 STEP/原始带面编号的三角化数据建立参考，统计容差带内边界 precision/recall、面匹配、过分割/欠分割，以及小倒角召回；冻结本轮参数，避免单凭观察某个面数调参。

## 方法来源与本实现的关系

- [Yan et al., Variational mesh segmentation via quadric surface fitting, CAD 2012](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/12/Variational-mesh-segmentation-via-quadric-surface-fitting.pdf)：提供结合曲面距离、法向与边界优化的思路。这里使用的是自己的线性定向代理、区域图优化及尺度约束，不是该论文算法的逐项复现。
- [CGAL Shape Detection](https://doc.cgal.org/latest/Shape_detection/index.html)：区域生长及几何模型拟合的可替代工业实现参考，本程序未依赖 CGAL。
- [Lifted Multicut 项目](https://www.mpi-inf.mpg.de/de/departments/computer-vision-and-machine-learning/research/image-segmentation/efficient-decomposition-of-image-and-mesh-graphs-by-lifted-multicuts)：边概率到图分割的背景；本实现额外使用区域曲面拟合与硬规模约束，未声称调用 lifted multicut 求解器。
